# Sys-Init
> Скрипт для автоматической настройки Ubuntu

## Установка и запуск
```bash
# 1. Скачайте скрипт 
curl -L -o sys-init.sh https://github.com/Kirutka/MakeScript/blob/master/sys-init.sh

# 2. Дайте права на выполнение
chmod +x sys-init.sh

# 3. Запустите
./sys-init.sh
```
